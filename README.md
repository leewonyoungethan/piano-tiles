# 건반 소나기

떨어지는 검은 건반을 순서대로 눌러 곡을 연주하는 피아노 타일 게임입니다.

- 피아노 255곡 / 드럼 247패턴, 왕초보부터 죽음까지 9단계 난이도
- 1인 / 2인 협동(왼손 반주 + 오른손 멜로디), 긴 건반 있음 / 없음 모드
- 500점 스테이지 클리어, 별(★★★)과 포인트
- 상점: 건반 색·모양, 효과, 배경, 악기 소리, 칭호, 부스터(부활권·방패·점수 2배·느리게)
- 순위: 곡별 TOP 10, 전체 랭킹 (이 기기 기준)
- 길게 누르는 타일
- 텅드럼 음색, 모든 곡에 반주 (1인 모드는 ‘반주’ 버튼으로 켜기)
- 탭, 클릭, 키보드(D F J K · 1–4 · 방향키) 지원
